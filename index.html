Linde Material Handling
Baoli Forklifts


Linde MH and Baoli Forklifts (same ownership) needed their websites replatformed from Sitecore to Next.js/React. We had a hard deadline of early February '26, so during the planning stage, we decided on a monorepo approach, which allowed us to build two websites from a single design system. All shared components and modules were built with Storybook, with the only difference between sites being the brand styling. We used Vanilla Extract CSS to enable variant-based styles, allowing us to handle both brand variations from a single stylesheet.

For the CMS, we used Sanity.io, leveraging the customisability of its structure/schema system to build a complete bespoke CMS solution.

Each component/module contained its own Sanity schema and query fragment, which fed into our page builder, allowing the client to create unique pages.

MusiMap

MusiMap.ai is a platform that analyses audio/songs with the MusiTag AI backend. It is used to generate music tagging such as genres, moods, situations, and similar artists,which is mainly used by publishing houses. Audio can be uploaded as MP3s or via a shared URL from Spotify.

I was hired to build out MusiMap.ai using Next.js/React with Storybook and integrate the backend APIs. Since this product is marketed in Europe, we also needed to include language translations based on a visitor's location. The marketing pages include many animations and inline videos to evoke the human side of music.

This is an ongoing project that will launch officially in 2026.
